## 🔧 Kurulum

### Otomatik Kurulum (Önerilen)
1. **Temayı İndir:** [viralay-ultra-fast-theme.tar.gz](viralay-ultra-fast-theme.tar.gz)
2. WordPress Admin → **Görünüm** → **Temalar** → **Yeni Ekle**
3. **Tema Yükle** → Dosyayı seç → **Şimdi Yükle**
4. **Etkinleştir**
5. **Cache Temizle** (tarayıcı + WordPress)

### Manuel Kurulum
```bash
cd wp-content/themes/
tar -xzf viralay-ultra-fast-theme.tar.gz
mv project viralay-ultra-fast
chown -R www-data:www-data viralay-ultra-fast
```
