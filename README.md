# Viralay Pro Theme

Premium viral video lisanslama platformu WordPress teması.

## Özellikler

✅ **Tamamen Hazır İçerikler**
- Tüm yasal sayfalar (Gizlilik, KVKK, Hizmet Şartları vb.) otomatik yüklenir
- Örnek SSS'ler 5 kategoride hazır gelir
- Persona sayfaları (Yayıncılar, Markalar, TV, AI) tasarlanmış halde

✅ **Gelişmiş Tema Paneli**
- Ana sayfa hero başlık/alt başlık ayarları
- Renk özelleştirme (Primary color)
- Simge stil seçenekleri (Solid, Gradient, Outlined)
- Font seçenekleri (Inter, Poppins, Roboto, Montserrat, Open Sans)

✅ **Modern Tasarım**
- Dark/Light mode desteği
- Responsive tasarım (mobile-first)
- Turkuaz renk teması
- Tailwind CSS 3.4

✅ **Custom Post Types**
- Viral Videos (video kategorileri ve etiketlerle)
- FAQ/SSS (kategorize edilmiş)

✅ **Otomatik Kurulum**
- Tema aktive edildiğinde tüm sayfalar yayınlanmış olarak oluşturulur
- İçerikler otomatik yüklenir
- Örnek kategoriler ve SSS'ler hazır gelir

## Kurulum

1. WordPress Admin Panel → Görünüm → Temalar → Yeni Ekle
2. "Tema Yükle" butonuna tıklayın
3. `trtr.zip` dosyasını seçin
4. "Şimdi Yükle" ve ardından "Etkinleştir"

Tema aktive edildiğinde:
- ✅ Tüm statik sayfalar içerikleriyle birlikte oluşturulur
- ✅ 6 örnek SSS eklenir
- ✅ Video kategorileri oluşturulur
- ✅ Her şey hazır!

## Tema Ayarları

WordPress Admin → **Viralay Ayarları** menüsünden:

### Genel Sekme
- Ana sayfa hero başlık
- Hero alt başlık
- Ana sayfada gösterilecek SSS sayısı

### Renkler & Simgeler Sekmesi
- Ana renk (Primary color) - Varsayılan: #14B8A6 (Turkuaz)
- Simge stili (Solid/Gradient/Outlined)

### Yazı Tipleri Sekmesi
- Başlık font seçimi
- Gövde font seçimi

### Sayfalar Sekmesi
- Otomatik oluşturulan sayfaların listesi
- SSS kategori bilgileri

## Sayfalar

Otomatik oluşturulan sayfalar:
- `/` - Ana Sayfa
- `/video` - Video Galerisi
- `/yayincilar` - Yayıncılar (Persona)
- `/markalar-ajanslar` - Markalar & Ajanslar (Persona)
- `/tv-produksiyon` - TV & Prodüksiyon (Persona)
- `/ai-veri-kullanimi` - AI Veri Kullanımı (Persona)
- `/hakkimizda` - Hakkımızda
- `/sss` - Sıkça Sorulan Sorular
- `/video-gonder` - Video Gönderme Formu
- `/lisans-al` - Lisans Alma
- `/giris-yap` - Giriş
- `/panel` - Kullanıcı Paneli
- `/gizlilik-politikasi` - Gizlilik Politikası
- `/hizmet-sartlari` - Hizmet Şartları
- `/kvkk-aydinlatma-metni` - KVKK Aydınlatma
- `/cerez-politikasi` - Çerez Politikası
- `/dmca-politikasi` - DMCA Politikası

## SSS Kategorileri

Otomatik oluşturulan kategoriler:
- **Genel** - Platform hakkında genel bilgiler
- **Başlangıç** - Nasıl başlanır, kayıt vs.
- **Satıcı (İçerik Sahibi)** - Video gönderme, onay süreci
- **Alıcı** - Lisans alma, kullanım
- **Ödemeler** - Ödeme süreçleri

## Destek

Herhangi bir sorunla karşılaşırsanız:
1. WordPress Admin → Viralay Ayarları → Sayfalar sekmesini kontrol edin
2. Sayfalar → Tüm Sayfalar'dan içeriklerin yüklendiğini doğrulayın
3. SSS → Tüm SSS'ler'den örnek soruların eklendiğini kontrol edin
